# ganbayard.github.io

Personal site of **Ganbayar Damdindorj** (ganbayard), live at **https://ganbayard.github.io**.

Plain HTML, CSS and JavaScript with a terminal theme. There's no build step, no framework and no trackers.

```
index.html            the page (all content lives here)
404.html              not-found page
assets/css/style.css  theme
assets/js/main.js     boot sequence, interactive shell, matrix rain, section reveal
assets/favicon.svg
```

## Edit

Content is plain HTML in `index.html`. Change it, commit and push to `main`, and GitHub Pages redeploys in about a minute.

## Preview locally

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

The hero terminal is interactive. Type `help` to see the commands.
